# External validation status

**EXTERNAL_CROSS_COHORT_TRANSFER_NOT_EXECUTED**

No independent source/target pair has a verified outcome crosswalk to Kaggle's broadly
described cross-sectional `cardio` label. External UCI files were inspected only to establish
site counts/schema; no external participant row, pretrained cohort checkpoint or prediction
is released. Other cohorts were assessed through official documentation only. No historical
private Phase1 participant data or checkpoints were accessed.

See [feasibility](TRANSFER_FEASIBILITY.md) for verified counts and missing eligibility items.
Nested CV and the age-subgroup study both use the same Kaggle development population and
are exploratory internal evidence informed by V1. They are neither prospective event
prediction nor external clinical validation. Future work requires independently sourced,
properly permitted cohorts, a defensible endpoint/time-horizon crosswalk, sufficient event
support, disjoint calibration and locked external evaluation. These are conditions for a
future study, not completed experiments.
